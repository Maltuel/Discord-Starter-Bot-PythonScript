# Discord-Starter-Bot-PythonScript
A simple but organized and easily expandable bot for discord. Done in "VS Code", be sure to have python and discord.py installed!

1. create a discord bot at "https://discord.com/developers/applications" (plenty of tutorials out there)
2. Paste your bot id and your server id into the code (**BOT_TOKEN** and **SERVER_ID**)
3. start in terminal of your IDE (I use Visual Studio Code) with **"py discord_bot_example.py"** (of course you can rename the .py to your liking)

Not the greatest accomplishment of all time, but me and some friends use this as a preset, maybe useful to someone :)
